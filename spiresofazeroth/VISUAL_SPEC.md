# Spires of Azeroth — VISUAL SPEC v2 (owner ruling 2026-10-17)

Owner (Chris) saw v1 and denied it: *"disappointed... I was hoping for it to look more like our Emberdeck
game, with actual animations, think literally Slay the Spire 2 but WoW characters; this is a bit small and 2D."*

The ENGINE (`js/engine/*`, data DSL in `SPEC.md`) is approved and stays. Everything the player SEES is
rebuilt to the bar below. No ads, no Wowhead calls, page stays static. Read `ARCHITECTURE.md` for the
module map and `SPEC.md` for data shapes before touching anything.

## The bar: Slay the Spire 2, WoW cast

- **Full-bleed stage.** The game fills the viewport (a 16:9 design space of 1920x1080 "stage units",
  letterboxed/scaled with `transform: scale()` on a `#stage` root so every number below is in stage px).
  The site masthead collapses to a thin top strip in play; on mobile portrait the stage rotates its
  layout (hand bottom, actors above) but stays full-bleed.
- **Painted zone backdrop with depth.** Each zone's battle backdrop is the real WoW loading-screen art
  from `/assets/loading-screens/<fdid>.jpg` (371 on disk; `@2x` siblings exist for some). Three layers:
  backdrop (slow parallax on pointer/gyro, 1.08x scale), a drifting fog/dust layer (canvas, additive,
  per-zone tint), a dark vignette + ground shadow band where the actors stand. Zone `theme` drives tint.
- **Real WoW characters in 3D.** Actors are real Blizzard models from the site's baked GLB library
  (`/assets/wowdex/models/<fdid>.glb`, manifest at `/assets/wowdex/models/manifest.json`; 1,141 NPC,
  114 character bodies, 627 mounts, 780 battle pets; mounts/pets carry idle animations, most NPCs do
  not). One transparent WebGL canvas (three.js from `/assets/vendor/three/` via the importmap the site
  already ships, see `assets/wgf-warband-3d.js`) sits between backdrop and HUD; actors stand in lanes:
  hero left (x 420, feet y 760), enemies right (x 1180/1420/1660, staggered depth). Camera is fixed
  3/4 low angle like StS. Lighting: key warm from upper-left, rim cool from behind, soft ground shadow
  blob per actor. Actor height target ~360 stage px (hero) / 280–420 (enemies by tier; bosses 520).
  - Animated GLB → play its idle clip (AnimationMixer). No clip → procedural breath (scale y 1±0.012,
    1.6 s) + weight shift. Attack = lunge toward target (anticipation 120 ms back, 160 ms forward eased
    out, hold at impact, 240 ms return). Hit = white emissive flash 90 ms + knockback 26 px + 2-frame
    hit-stop. Death = tip back 12°, sink 40 px, dissolve (opacity 1→0 over 600 ms) + dust puff.
    Block gain = brief gold rim light. Status apply = colour pulse by status.
  - Enemy → model mapping is DATA: `data/models.json` `{ "<enemyId>": { "fdid": N, "scale": 1.0,
    "yaw": 0 } }` generated by `tools/spires/map-models.mjs` from the manifest: exact name match, else
    the enemy's `npcId` in `entity_ids`, else family/type keyword (wolf, boar, bear, spider, raptor,
    whelp, crocolisk, elemental...), else a class default plaque. Every enemy WITHOUT a model is listed
    in `data/models.MISSING.md` for the creature-bake lane. Never leave an enemy invisible: the fallback
    is a 2D "shadow silhouette" card (zone-tinted silhouette plate with the icon inset, still animated by
    the same lunge/hit/death choreography) — not a bare icon.
  - Hero = a character body from the manifest (`kind: character`, keyed race/sex — see
    `wgf_models3d.py` `character()`), one per class: warrior human-m, paladin dwarf-m, hunter nightelf-f,
    rogue human-f, priest undead-f, shaman orc-m, mage gnome-f, warlock undead-m, druid tauren-m. Gear
    assembly via `assets/wgf-model-assemble.js` is optional polish, not required for v2.
- **Real VFX, not primitives.** Reuse Emberdeck's flipbook kit (owner-made, original):
  `C:\Code\cinderwake\assets\fx\*.png` (27 sheets, luminance+alpha, 256 px frames, `index.json` has
  frames/columns/fps/pivot/blend/hold_peak) + `particles.png` atlas. Copy into
  `spiresofazeroth/assets/fx/` as WebP q92 and ship `index.json`. A canvas-2D `fx` layer above the 3D
  canvas plays flipbooks (additive via `globalCompositeOperation: lighter`, tinted per element through an
  offscreen tint pass), runs a particle system (burst/ring/trail/fountain/drift; velocity, gravity,
  drag, spin, size/alpha curves; hundreds per impact), and a choreography table `js/fx/choreo.js`:
  element × kind → recipe. Elements: steel, fire, frost, arcane, nature, holy, shadow, blood, wind,
  stone. Card → element by class default and spell school (`spellId`/icon prefix: `spell_fire_*`→fire,
  `spell_frost_*`→frost, `spell_shadow_*`→shadow, `spell_holy_*`→holy, `spell_nature_*`→nature,
  `ability_*`/`inv_sword_*`→steel, `spell_arcane_*`→arcane). Kinds: attack (travel streak → impact
  flipbook at target + shards/sparks + ground dust + white flash + hit-stop + screen kick scaled by
  damage + damage number punch → settle embers), skill/block (shield_shimmer rising on hero + ring
  pulse), power (buff_glyph_rise + fountain + faint persistent aura), heal (heal_sparkle + motes).
  Enemy attacks use the same kit (claw/bite/steel/spit). Reduced motion: half particles, no shake,
  flipbooks still play. Impact instant MUST line up with the engine's damage application (the UI
  awaits the choreography promise before applying the next effect; see `combat.js` `playFx`).
- **Cards like StS2.** Stage-space card 260x380. Full-art frame: the spell icon (`/assets/icons/`
  256 px variant if present, else 56 px upscaled) fills the top 55% behind a blurred, saturated copy of
  itself with a class-colour gradient, framed by a nine-slice from `/assets/ui/` (wood/gold frames exist;
  pick one per rarity: basic plain, common bronze, uncommon silver, rare gold). Name in `frizqt`
  (WoW's Friz Quadrata, `/assets/fonts/frizqt.woff2`), body text `arialn`, title screens `morpheus`.
  Cost orb top-left in class colour; type banner (Attack/Skill/Power) under the art; keyword text with
  gold highlights; upgraded cards get a green name + "+" and a brighter frame. Hand fans in an arc at
  the bottom (rotation ±14°, lift on hover 60 px + scale 1.18 + z-index), neighbours part. Playing:
  click → card lifts; targeted cards show a bezier targeting arrow (dashed, class colour) from the card to
  the pointer; release on an enemy. Non-targeted: drag above the hand line. The played card "ghosts" into
  the hero (300 ms, shrink + fade) and the choreography fires. Draw: cards fly from the draw pile
  (bottom-left) into the fan with 40 ms stagger; discard flies to the pile bottom-right; exhaust burns
  (orange edge + dissolve). Energy orb bottom-left (class resource shown as a WoW-style orb: rage red,
  mana blue, energy yellow, focus orange, etc.) with a count punch on change.
- **HUD.** Top bar: hero name/class, HP bar (WoW red gradient, numeric), gold with coin icon, relic
  strip (icons with tooltip), potions belt (3 slots), deck/map/settings buttons — all on WoW nine-slice
  chrome from `/assets/ui/`. Enemies: name plate + HP bar above, **intent** above that (StS-style: icon +
  number, attack = sword with damage, multi = ×N, block = shield, buff = up arrow, debuff = down arrow,
  unknown = ?), status pips row under the HP bar (icon + stack, tooltip). Floating numbers: damage
  (white→red punch, 1.3x scale pop, drift up), block (blue), heal (green), with slight random x jitter.
  Turn banner slides in ("Your turn" / "Enemy turn") with a horizontal gold rule.
- **Map like StS2.** Vertical spire path drawn on parchment-tinted zone art: nodes are WoW icons on
  round frames (monster = red, elite = purple with a flame, rest = campfire, vendor = coin, event = ?
  scroll, treasure = chest, boss = big skull plate at the top with the boss portrait). Paths are dotted
  lines; reachable nodes pulse; current node has a player marker. Zone pick between acts = three large
  zone cards with loading-screen art, name in morpheus, continent ribbon.
- **Other screens on the stage, not in a form.** Rewards: cards fan out large with a gold "choose one"
  banner; relics/gold/potion drop as plates. Shop: a vendor NPC model (any merchant body) on the left,
  goods on a cloth table. Rest: campfire glow + ember particles, options as big plates. Events: parchment
  with the event text, choices as WoW-style buttons, illustrated by the zone backdrop. Run end: hero model
  with a victory/defeat banner, stat scroll.
- **Sound (v2, optional stub).** `js/audio.js` seam with a muted default and a toggle; ship no audio yet.
- **Performance.** 60 fps on a 2020 laptop: ≤ 6 GLBs loaded per fight, draw calls budgeted, flipbooks
  pre-decoded, particles pooled, `prefers-reduced-motion` honoured, pause the loops when the tab is
  hidden. First paint < 1.5 s on cable; models stream in after the backdrop (actors fade in).
- **Mobile.** 390 px portrait: stage scales to width, hand becomes a scrollable strip, actors shrink,
  tap-to-target with a highlight ring instead of drag.

### Per-card spell looks (v2 spellfx)
`data/fx/cards.json` (merged by `tools/merge-cardfx.mjs` from `data/fx/cards.<group>.json`, schema in `data/fx/MAPPER_BRIEF.md`) gives every card a real-WoW look
(tint/tint2, travel, impact sheet, shape, particles, shake, optional n/hops/dur). `js/fx/cardfx.js` holds the shape recipes
(slash, arc, bolt, nova, beam, shield, aura, heal, cleave, whirl, rain); `choreo.js` uses a card's look when present and falls back to element x kind.
`travel: "none"` on a bolt = dart/arrow style. Contact sheet: `docs/v2-fx/signature-cards.jpg`.

## Unit frames (owner ruling 2026-10-17: 1:1 WoW Classic, real Blizzard art only)

Owner: "The health bar should be just like the IN-GAME WoW Classic HP bars, and same with the rage bar." No CSS-drawn pills.
- **Player frame** (top-left of the top bar): `Interface/TargetingFrame/UI-TargetingFrame` mirrored (portrait left) over a
  `UI-StatusBar` green health bar and, beneath it, the class power bar (`.sp-pw`, same texture): rage red, mana blue,
  energy yellow, focus orange. Numbers "cur / max" centred, WoW `arialn`; class name in the name slot (`frizqt` gold),
  Act number in the level badge. The 256x128 texture is positioned in texture px inside `.sp-pf__c` and scaled by `--s`.

  The card-energy orb stays.
- **Enemy / hero floor plates**: name above, `Interface/Tooltips/Nameplate-Border` over the status-bar HP (`.sp-np`; red for
  enemies, green for the hero), numbers inside the bar, `Nameplate-Glow` on targetable/target. Block badge, status pips,
  intent and the yellow damage-ghost trail are unchanged. Class names/ids (`sp-hp`, `sp-hp__fill/ghost/txt`, `sp-eplate`) kept.
- **Assets** `assets/ui/unitframe/` (CSS-relative `../assets/ui/unitframe/`; NOT the shared site `/assets/ui`): extracted from
  the retail client files via wago.tools CASC (`/api/casc/<FileDataID>`; ids from the community listfile) and converted

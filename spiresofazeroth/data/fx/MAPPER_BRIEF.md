# Spell VFX mapper brief (Spires of Azeroth v2)
Goal: for EVERY card in your assigned files, choose a look matching the REAL classic WoW spell visual (its actual colours + motion in game; NOT the icon colour). Write ONLY your output file `data/fx/cards.<group>.json` (a JSON object {cardId: look}). Touch nothing else.
Cards: data/classes/<class>.json -> `cards` (and `tokens` if present); data/neutral-cards.json `cards`; data/status-cards.json `cards`. Each has id, name, icon, spellId, type (attack|skill|power), target, effects. Use name+spellId to recall the real spell. Include upgrade-only variants? No: one entry per `id`.
Look schema (all keys required except n/hops/note):
{ "tint":"#hex" main colour of the real spell, "tint2":"#hex" secondary/hot core colour,
  "travel":"<sheet>|none" flipbook/trail style used on the projectile path (none = no projectile, effect appears at target/caster),
  "impact":"<sheet>" flipbook at the impact point (target for attacks, hero for self buffs),
  "shape":"slash|arc|bolt|nova|beam|shield|aura|heal|cleave|whirl|rain",
  "scale":0.7-1.8, "particles":"sparks|embers|frost|arcane|leaves|holy|shadow|blood|stone|wind", "shake":0-1,
  "n": optional count (3 arrows, 3 slashes, 3 missiles, rain strikes; default 1), "hops": optional (chain lightning bounce count),
  "via":"exact|known|school-guess", "note":"<=8 words optional" }
Shapes: slash = weapon slash arc(s) at target (n = number of slashes); arc = bigger curved sweep at target (ranged melee-like, e.g. Whirlwind slice, Shockwave line); bolt = projectile caster->target with head+trail then impact (n = bolts fired in a spread); nova = ring expanding from caster (self-centred AoE, Frost Nova, Holy Nova, Thunderclap); beam = line from caster to target with flicker (Lightning Bolt, Drain Life, Moonfire from above uses rain n=1); shield = shield shimmer on hero (blocks); aura = buff/power glow on hero (persistent for powers); heal = heal sparkle/column on hero or target; cleave = wide horizontal arc sweeping across all enemies; whirl = ring spin around hero (Whirlwind, Blade Flurry); rain = top-down impacts on target (Moonfire/Starfall/Rain of Fire/Meteor/Holy Fire pillar/Smite from above, n strikes).
Sheets (impact/travel; tinted at runtime so pick by SHAPE of motion, tint carries colour): slash_arc_a slash_arc_b slash_arc_c (crescent slashes) hit_star impact_burst (round burst) shockwave_ring spark_burst thorn_lash vine_whip wind_crescent shards (shatter shards) smoke_puff dust_ground leaf_whirl shadow_wisp blood_mist ember_rise flame_tongue lightning_bolt_a lightning_bolt_b (jagged vertical bolts) frost_bloom holy_ray (vertical light column) shield_shimmer heal_sparkle buff_glyph_rise (rising rune glow).
Rules: `travel` and `impact` must be in that sheet list (travel may be "none"). Colours must be the spell's real in-game colours (Heroic Strike purple/violet, Cleave green, Mortal Strike red, Rend blood red, Charge dust, Fireball orange bolt, Frostbolt pale blue + ice shards, Arcane Missiles 3 violet bolts, Shadow Bolt purple-black, Corruption green-black aura, Holy Light gold column, Flash of Light yellow, Lightning Bolt blue-white jagged beam, Chain Lightning hops, Wrath green nature bolt, Moonfire silver beam from above, Sinister Strike yellow-white slash, Eviscerate red multi-slash, Backstab dark slash, Multi-Shot 3 arrows, Aimed Shot single arrow with glint, Serpent Sting green dart, Shield Block gold shimmer, Battle Shout/stances red aura, etc.). via=exact when you know the spell's visual, known when it is a related/known-school spell, school-guess when you are guessing from the school. Be honest. Non-spell cards (status curses/junk, neutral tricks) get a fitting mundane look (via school-guess). Vary shape/impact/scale across cards so the deck does not feel samey. Attack-type cards must use a target-side shape (slash|arc|bolt|beam|cleave|rain|nova|whirl); skill/power must be self-side (shield|aura|heal|nova|whirl) unless the spell clearly hits an enemy (debuff on target -> bolt/beam/rain/aura okay).
Validate before finishing: `node -e` that every id of your cards has an entry, all sheets exist in assets/fx/index.json, all hex valid, shape/particles in the lists. Report back in 3 lines: counts exact/known/school-guess. Do not modify anything outside your output file. Worktree: <local path> (use bash, cap output).
